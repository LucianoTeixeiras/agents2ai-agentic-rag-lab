# ADR-005 — Azure OpenAI e Databricks como fase 2 prática

- **Status:** Proposto

## Contexto
Deixam de ser “stubs só no README”: tornam-se **fase 2 planejada e prática**, sujeita a credenciais, acesso e **custo autorizado**. Nada é provisionado na fase 1.

## Decisão
LAB-08/09 = fase 2. Databricks: Bronze JSON/páginas ANP → Silver → Gold; MLflow mínimo se viável. Vector Search só se útil/disponível para docs — não requisito artificial.

## Consequências
(+) Honestidade + caminho claro (−) Fase 2 pode ficar bloqueada sem budget
