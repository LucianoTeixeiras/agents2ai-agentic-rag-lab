# ADR-006 — Minimização de dados ANP no artefato público

- **Status:** Proposto

## Decisão
Usar API real; no git publicar só snapshots mínimos + atribuição ANP. Não afirmar texto de licença específico não confirmado. Métricas sempre com escopo explícito sobre resultado paginado/recuperado.

## Consequências
(+) Menor risco de over-sharing (−) Dataset “completo” fica fora do repo
