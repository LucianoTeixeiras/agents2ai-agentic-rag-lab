# AGENTS.md — instruções para agentes de código

Projeto: laboratório público de IA (RAG + MCP read-only + FastAPI) sobre a API ANP Revendedores GLP.

Antes de qualquer tarefa:
1. Leia [`docs/prompts/CORE-RULES.md`](docs/prompts/CORE-RULES.md).
2. Abra o prompt canônico da issue em [`docs/prompts/tasks/`](docs/prompts/tasks/) (arquivo `<CHAVE>_<slug>.md`) e siga o **Prompt Executivo**.
3. Ao concluir, gere o relatório em `docs/relatorios/` a partir de [`docs/prompts/templates/RELATORIO-FECHAMENTO.md`](docs/prompts/templates/RELATORIO-FECHAMENTO.md).

Nunca: commitar segredos, chamar a API live no CI, calcular métricas com o LLM, marcar issues como Done ou fazer merge sem revisão humana.
